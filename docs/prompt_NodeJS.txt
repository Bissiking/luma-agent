Développe un agent de monitoring système nommé "N-2.0.0-Grizzly" en Node.js qui collecte des métriques système et les envoie à un serveur central via une API REST.

L'agent doit:
1. Collecter des métriques système (CPU, mémoire, disque, réseau [Peut avoir plusieurs disque/partition], docker [Si /var/run/docker.sock], proxmox [Features])
2. Vérifier l'état de services web via des requêtes HTTP
3. S'authentifier auprès d'une API avec UUID et token
4. Envoyer des données régulièrement selon un intervalle configurable
5. Détecter et signaler des anomalies basées sur des seuils configurables
6. Conserver une empreinte légère sur le système

Spécifications techniques:
- Node.js 16+ compatible
- Architecture modulaire avec architecture basée sur des classes/composants
- Utilisation des Promises et async/await
- Logging configurable (winston ou similar)
- Gestion des erreurs robuste (perte de connexion, échecs d'API)
- Support pour configuration locale (fichier JSON) et distante (API)

L'API utilise les endpoints suivants:
- POST /api/v1/monitoring/agent/checkin: Signaler que l'agent est actif
- GET /api/v1/monitoring/agent/configuration: Récupérer la configuration
- POST /api/v1/monitoring/service/update: Envoyer des données de service
- POST /api/v1/monitoring/alert/create: Signaler une alerte

L'authentification se fait avec les headers HTTP:
- X-Agent-UUID: l'UUID unique de l'agent
- X-Agent-Token: le token d'authentification

Utilise des bibliothèques standards et reconnues comme requests, psutil et pyyaml.
